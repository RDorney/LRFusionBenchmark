# Data licences

The `LICENSE` file covers the **code** in this repository under the MIT licence. Data files fall
under the terms below.

## Third-party data redistributed here

| File | Source | Licence |
|---|---|---|
| `Known_Fusions/DepMap_OmicsFusionFiltered.csv` | DepMap 25Q2 Public | CC BY 4.0 |
| `Known_Fusions/Model.csv` | DepMap 25Q2 Public | CC BY 4.0 |
| `Known_Fusions/Cell_Line_Fusions/HUH7 fusions.csv` | DepMap 25Q2 Public | CC BY 4.0 |

DepMap releases its public data under CC BY 4.0, which permits redistribution with attribution. The
release used here is **25Q2 Public**, announced 5 June 2025 and downloaded in August 2025. From 25Q2
onward DepMap distributes through AWS rather than Figshare, so there is no Figshare DOI to cite for
this release.

Please cite as:

> DepMap, Broad (2025). *DepMap 25Q2 Public*. Broad Institute. https://depmap.org/portal/

DepMap's terms state the data are for research use and are not intended for clinical or commercial
purposes. Use of this repository for academic research is consistent with those terms.

## Data generated by this project

Everything else under `Fusions/`, `Figures/Input_dataframes/`, `SimulatedData/` and
`CellLineData/`, together with the curated Huh7 truth set
(`Known_Fusions/KnownHuh7Fusion_ah.csv` and `Known_Fusions/KnownHuh7FusionsLiterature_2026.csv`),
was produced by this project and is released under the same MIT terms as the code.

## Reference files not included

The GENCODE annotation and the GRCh38 genome are not redistributed here: they are large public
files better obtained from source. The analysis used GENCODE v44 (and v43 for the JAFFAL arm), with
Ensembl annotation through EnsDb v110 and v109 respectively.

Raw sequencing data are deposited separately; see the data availability statement in the manuscript.
